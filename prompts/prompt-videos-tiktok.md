## Tarefa

Crie **10 scripts de vídeo para TikTok** (máximo 2 minutos cada) baseados nos **10 conteúdos principais** do ebook "Aprender a Aprender".

Cada vídeo deve ensinar uma técnica de estudo baseada em evidências científicas, no estilo edutainment — educativo, rápido e engajante.

## Os 10 tópicos (um por vídeo)

1. **Active Recall** — a técnica mais eficaz para aprender
2. **Repetição Espaçada** — como vencer a curva do esquecimento
3. **Técnica Feynman** — se não consegue explicar de forma simples, não entendeu
4. **Interleaving** — por que alternar matérias melhora o aprendizado
5. **Pomodoro + Foco** — como gerenciar a atenção
6. **Dual Coding** — texto + imagem = aprendizado 2x mais eficaz
7. **Desirable Difficulties** — por que o difícil é bom para aprender
8. **Metacognição** — a habilidade de pensar sobre o próprio pensamento
9. **Elaboração e Autoexplicação** — pergunte "por quê?" enquanto estuda
10. **Sono e Consolidação** — dormir é parte do aprendizado

## Estrutura de cada script

Para cada vídeo, produza:

```
## Vídeo N — [TÉCNICA]

### 📱 Formato TikTok
- **Duração:** [X] segundos (máximo 120s)
- **Estilo:** Edutainment / Ciência popular
- **Tom:** Energético, acessível, curioso
- **Público:** Jovens adultos (18-35), estudantes universitários

### 📝 Script Narrado (o que o locutor fala)
[Escreva o texto completo, de forma coloquial e direta, como se estivesse falando com um amigo. Use linguagem de TikTok: rápido, sem rodeios, com gancho no início.]

### 🎬 Direções de Cena (o que aparece na tela)
Para cada frase ou pausa, descreva:
- Tipo de takes (selfie do apresentador, gravação de tela, animações)
- Textos na tela (captions / texto sobreposto)
- Emojis usados
- Transições sugeridas
- Cortes ágeis

### 🔊 Elementos de Produção
- Música de fundo: [sugestão de estilo/gênero/andamento]
- Efeitos sonoros sugeridos
- Texto da legenda (para copiar e colar)

### ⏱️ Timeline
Segundo a segundo: o que acontece, o que é dito, o que aparece.

### 📌 Call to Action (CTA)
O que o espectador deve fazer depois: seguir, comentar, salvar, compartilhar.

### 📚 Referência Científica
Cite o estudo principal (autor, ano, descoberta central) de forma simples — para quem quiser se aprofundar.
```

## Instruções de estilo

- **Primeiro segundo é CRÍTICO:** Comece com uma pergunta provocativa ou afirmação chocante
- **Use analogias visuais:** Sempre que possível, mostre uma metáfora visual (ex.: cérebro como academia, memória como arquivo, etc.)
- **Números e dados:** Inclua pelo menos UM número/estatística por vídeo
- **Humor leve:** Um comentário engraçado ou surpresa mantém o engajamento
- **CTAs naturais:** Não peça para seguir de forma genérica — conecte o CTA ao conteúdo
- **Evite jargão:** Se precisar usar termo técnico, explique em 2 segundos
- **Captions:** Cada script deve incluir o texto da legenda pronta para copiar e colar
